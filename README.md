# Văn phòng số Trịnh · OpenClaw

Dashboard văn phòng ảo theo dõi đội AI agent OpenClaw theo thời gian thực (mô phỏng).

## Chạy local

```bash
npm install
npm run dev
```

Mở địa chỉ Vite in ra (mặc định `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Tính năng

- Sàn văn phòng ảo với agent Trịnh và đội OpenClaw
- Trạng thái trực tiếp: đang làm / sẵn sàng / họp / tuần tra
- Giao việc và triệu tập họp nhanh
- Nhật ký hoạt động cập nhật liên tục

Thiết kế theo hướng mực xanh – vàng đồng, tối ưu desktop và mobile.
